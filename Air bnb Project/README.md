# 🏠 Airbnb Data Analysis Using Python  

## 📘 Overview  
This project analyzes Airbnb listings data to uncover insights about pricing trends, room types, neighborhood patterns, and review activity using Python data analysis libraries.  

---

## 🎯 Objective  
To explore Airbnb data and understand how factors like location, room type, and reviews affect pricing and availability.  

---

## 🧰 Tools & Libraries  
- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Plotly (Interactive Visuals)**

---

## 📂 Dataset Information  
- **File Name:** `Air pnb data.csv`  
- **Rows:** ~100,000  
- **Columns:** 24 features  
- **Key Attributes:**  
  - `neighbourhood group`, `room type`, `price`, `reviews per month`, `availability 365`, `last review`  

---

## ⚙️ Data Cleaning & Preparation  
- Handled **missing values** using imputation and removal.  
- Fixed **data types** (converted `price`, `service fee` to float).  
- Dropped unnecessary columns like `license` and `house_rules`.  
- Removed duplicate rows and reset index.  

---

## 🔍 Exploratory Data Analysis (EDA)
### Performed analyses to uncover:
1. **Distribution of Prices** – to identify the overall price trend.  
2. **Room Type Distribution** – count of different room types.  
3. **Neighbourhood Group Analysis** – which areas have the most listings.  
4. **Price vs Room Type** – comparison of pricing by accommodation type.  
5. **Reviews Over Time** – monthly review trends.  
6. **Availability vs Review Rate** – relation between booking availability and ratings.  
7. **Geospatial Map** – plotted listings by latitude and longitude using Plotly Mapbox.  
8. **Correlation Heatmap** – to analyze numerical feature relationships.  

---

## 📊 Key Insights  
- **Entire homes/apartments** are most common and command higher prices.  
- **Manhattan** has the maximum listings, followed by **Brooklyn**.  
- **Listings with more availability** tend to have **fewer reviews**, showing lower occupancy.  
- **Review rates and prices** have a moderate positive correlation.
